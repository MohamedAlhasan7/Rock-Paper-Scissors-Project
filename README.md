# Rock Paper Scissors Game 🎮

A console-based **Rock Paper Scissors** game built with **C++**, developed as part of my learning journey in programming and problem-solving.

The project focuses on applying fundamental programming concepts while practicing clean code organization using header and source files.

## 📌 Features

* Player vs. Computer gameplay
* Configurable number of rounds
* Random computer choices
* Round winner determination
* Final game winner calculation
* Round-by-round results
* Screen colors based on the round winner
* Option to play multiple games
* Input validation

## 🛠️ Technologies & Concepts

* **C++**
* Enums
* Structures (`struct`)
* Functions
* Loops and conditional statements
* Random number generation
* Function decomposition
* Header and source files
* Basic modular programming

## 🎯 How the Game Works

1. Enter the number of rounds.
2. Choose:

   * `1` → Rock
   * `2` → Paper
   * `3` → Scissors
3. The computer randomly selects its choice.
4. The winner of the round is determined.
5. The result is displayed.
6. After all rounds, the final game result is displayed.
7. You can choose to play again.
